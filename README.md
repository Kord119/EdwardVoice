# Edward Agent

Локальный голосовой ассистент для управления устройствами и ответов на вопросы. Работает полностью на вашем компьютере: распознавание речи, нейросеть и логика — всё оффлайн. В сеть уходят только запросы к внешним API (StarLine, Edge-TTS) и только когда это необходимо.

## Возможности

**Распознавание речи.** Модель Vosk работает локально, интернет не требуется. Ассистент активируется по wake-word «Привет Эдвард» и понимает команды на русском языке.

**Локальная нейросеть.** Используется Qwen 2.5 7B через Ollama. Чтобы не занимать VRAM без необходимости, LLM активируется по запросу — при первом сложном вопросе программа спросит подтверждение, после чего модель останется в памяти до ручного отключения.

**Управление автомобилем.** Через официальный API StarLine доступны запуск и остановка двигателя, постановка и снятие с охраны, получение статуса (состояние двигателя, температура, уровень топлива).

**Управление телевизором.** Включение через Wake-on-LAN с двойной отправкой пакета для надёжности. Выключение и базовые команды через ИК-интерфейс (при наличии Broadlink) или MQTT (для Hisense VIDAA).

**Озвучивание.** Основной движок — pyttsx3 (оффлайн, использует системные голоса Windows). При недоступности автоматически переключается на Edge-TTS.

## Примеры использования

```
— Привет Эдвард, который час?
— Сейчас пятнадцать тридцать.

— Привет Эдвард, заведи машину.
— Запускаю двигатель. Машина прогреется через несколько минут.

— Привет Эдвард, статус машины.
— Двигатель выключен, на улице минус пять, машина закрыта.

— Привет Эдвард, включи телевизор.
— Включаю телевизор.

— Привет Эдвард, что такое квантовая запутанность?
— [после активации LLM даёт краткий ответ на русском]
```

## Системные требования

- Windows 10 / 11
- Python 3.10 или новее
- 8 ГБ RAM (16 ГБ рекомендуется для комфортной работы с LLM)
- Видеокарта с 4+ ГБ VRAM для нейросети (возможна работа на CPU, но медленнее)
- Микрофон
- VLC Media Player для воспроизведения аудио

## Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/your-username/edward-agent.git
cd edward-agent
```

### 2. Виртуальное окружение и зависимости

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Установка Ollama и модели

Скачайте Ollama с [официального сайта](https://ollama.com/download), затем загрузите модель:

```bash
ollama pull qwen2.5:7b
```

Модель занимает около 5 ГБ — лучше скачать заранее.

### 4. Модель распознавания речи Vosk

Модель не включена в репозиторий из-за ограничений GitHub на размер файлов. Скачайте её отдельно:

1. Перейдите на [alphacephei.com/vosk/models](https://alphacephei.com/vosk/models)
2. Найдите `vosk-model-small-ru-0.22`
3. Скачайте и распакуйте архив в корень проекта

Итоговая структура должна выглядеть так:

```
edward-agent/
└── vosk-model-small-ru-0.22/
    ├── am/
    ├── conf/
    ├── graph/
    └── ivector/
```

### 5. VLC Media Player

Скачайте с [videolan.org](https://www.videolan.org/vlc/). По умолчанию устанавливается в `C:\Program Files\VideoLAN\VLC\vlc.exe`. Если путь отличается — обновите переменную `VLC_PATH` в `edward_agent.py`.

## Настройка

### Телевизор

В файле `edward_agent.py` укажите параметры вашего ТВ:

```python
TV_MAC = "AA:BB:CC:DD:EE:FF"   # MAC-адрес
TV_IP  = "192.168.1.100"       # IP-адрес
```

MAC-адрес можно найти в настройках ТВ (раздел «Сеть» → «Информация») или в административной панели роутера. Для работы Wake-on-LAN функция должна быть включена в BIOS и в настройках сетевого адаптера телевизора.

### StarLine (управление автомобилем)

1. Зарегистрируйтесь как разработчик на [developer.starline.ru](https://developer.starline.ru/)
2. Создайте приложение и получите `App ID` и `App Secret`
3. Создайте файл `.env` в корне проекта:

```env
STARLINE_APP_ID=your_app_id
STARLINE_APP_SECRET=your_secret
STARLINE_USERNAME=your_email@example.com
STARLINE_PASSWORD=your_password
```

При первом подключении StarLine может запросить капчу — это штатная защита от автоматических запросов. После успешного ввода токен действует 24 часа.

## Запуск

Запустите `edward_agent.bat` двойным кликом или через консоль:

```bash
venv\Scripts\activate
python edward_agent.py
```

При старте программа выводит список доступных команд и переходит в режим ожидания wake-word.

## Доступные команды

### Активация и завершение
- **«Привет Эдвард»** — активация ассистента
- **«Выход» / «Пока» / «Стоп»** — завершение работы

### Автомобиль (StarLine)
- **«Заведи машину»** — запуск двигателя
- **«Заглуши машину»** — остановка двигателя
- **«Закрой машину»** — закрыть двери и поставить на охрану
- **«Открой машину»** — открыть двери и снять с охраны
- **«Статус машины»** — краткая сводка о состоянии

### Телевизор
- **«Включи телевизор»** — отправка WOL-пакета (двойная отправка для надёжности)
- **«Выключи телевизор»**

### Нейросеть
По умолчанию LLM не загружена. При первом вопросе, требующем нейросети, ассистент спросит разрешение и активирует модель. Команды ручного управления:

- **«Активируй LLM»** — загрузить модель в память
- **«Отключи LLM»** — выгрузить модель и очистить историю

После активации можно задавать любые вопросы на русском языке.

### Вспомогательные
- **«Который час?»** / **«Какая дата?»**
- **«Что ты умеешь?»** — список команд
- **«Очисти память»** — сброс истории диалога

## Архитектура

```
edward-agent/
├── edward_agent.py           # главный модуль: микрофон, wake-word, маршрутизация
├── llm_controller.py         # работа с Ollama и Qwen 2.5
├── starline_controller.py    # клиент API StarLine
├── tv_controller.py          # управление ТВ (WOL, MQTT)
├── edward_agent.bat          # скрипт запуска для Windows
├── requirements.txt          # зависимости Python
├── .env                      # учётные данные (исключён из git)
├── .gitignore
├── README.md
└── vosk-model-small-ru-0.22/ # модель Vosk (скачивается отдельно)
```

Каждый контроллер вынесен в отдельный файл, что упрощает поддержку и расширение функциональности.

### Поток обработки команды

```
микрофон
   ↓
Vosk — распознавание речи (оффлайн)
   ↓
детектор wake-word «Привет Эдвард»
   ↓
извлечение команды из фразы
   ↓
process_command() — маршрутизация:
   ├─ быстрые ответы (время, дата)
   ├─ tv_controller
   ├─ starline_controller
   └─ llm_controller
   ↓
TTS (pyttsx3 / Edge-TTS) → динамики
```

## Решение типовых проблем

| Проблема | Решение |
|----------|---------|
| `ModuleNotFoundError: No module named 'vosk'` | `pip install vosk sounddevice numpy` |
| Модель Vosk не найдена | Проверьте, что папка `vosk-model-small-ru-0.22` находится в корне проекта |
| Ollama не отвечает | Убедитесь, что Ollama запущен (иконка в трее). Проверьте: `ollama list` |
| StarLine запрашивает капчу | Это защита от частых запросов. После ввода токен действует 24 часа |
| Ошибка озвучивания «No audio was received» | Программа автоматически переключится на pyttsx3. Проверьте наличие русских голосов в системе |
| LLM отвечает медленно | Используйте модель меньшего размера: `ollama pull qwen2.5:3b` |

## Приватность

Распознавание речи и работа нейросети выполняются локально — разговоры не покидают устройство.

Внешние сетевые запросы происходят только в двух случаях:
- обращение к StarLine API при управлении автомобилем;
- обращение к Edge-TTS, если локальный pyttsx3 недоступен (передаётся только текст для озвучивания).

Файл `.env` с учётными данными исключён из git через `.gitignore`.
